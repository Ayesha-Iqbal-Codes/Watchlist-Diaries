📝 Watchlist Diaries
Tech Stack:
React.js, Node.js, Express, MongoDB, Tailwind CSS

🌐 Live Demo
Visit Website: https://watchlist-diaries.vercel.app

📜 Overview
Watchlist Diaries is a personal web app where I've added reviews for all the movies and TV shows I've watched. It features special lists and allows users to log in and add their wishlist of reviews they want to see. Built using React, Node.js, Express, MongoDB, and styled with Tailwind CSS.
